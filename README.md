# RuneMages

Дуэль двух магов-программистов — стратегическая игра, где игроки строят схемы из рун для маршрутизации маны.

## Описание игры

В RuneMages два игрока соревнуются, собирая чистую ману в свою чашу и отправляя грязную ману оппоненту. Игроки не управляют шариками напрямую — вместо этого они расставляют руны на поле, которые изменяют направление движения маны.

### Основные механики

- **Поле**: сетка 4×8 клеток у каждого игрока
- **Мана**: шарики появляются слева и движутся вправо к чаше
- **Руны**: специальные символы, которые изменяют поведение маны
- **Волны**: матч состоит из 5 волн
- **Фазы**: каждая волна имеет фазу подготовки (Prep) и фазу потока (Flow)

### Типы маны

- **Белая** (White): +1 очко в чаше
- **Красная** (Red): +2 очка в чаше, через ловушку даёт 2 грязных шарика оппоненту
- **Чёрная** (Black): -1 очко в чаше, через ловушку не даёт мусор оппоненту
- **Грязная**: -1 очко в чаше (получена от оппонента)

### Типы рун

1. **Стрела** (Arrow): меняет направление движения маны (↑ → ↓ ←)
2. **Отражатель** (Mirror): отражает ману по диагонали (/ или \)
3. **Разделитель** (Splitter): дублирует шарик (Y↑ или Y↓)
4. **Ускоритель** (Accelerator): ускоряет шарик (двойной шаг)
5. **Отвод в ловушку** (TrapOut ☠): отправляет ману оппоненту как грязную

### Лимиты рун на волну

- Стрелы: 8
- Отражатели: 4
- Разделители: 3
- Ускорители: 3
- Ловушки: 3

## Установка и запуск

### Требования

- Node.js (версия 18 или выше)
- npm или yarn

### Установка зависимостей

```bash
npm install
```

### Запуск игры

Для запуска UI в режиме разработки:

```bash
npm run dev
```

Игра откроется в браузере по адресу `http://localhost:5173` (или другому порту, который покажет Vite).

### Другие команды

- `npm run build` — собрать проект для продакшена
- `npm run build:game` — собрать только игровой движок (TypeScript)
- `npm run dev:sandbox` — запустить тестовый sandbox (консольный режим)
- `npm run preview` — предпросмотр собранной версии

## Как играть

### Интерфейс

- **Две доски**: слева — Player 1 (ваше поле), справа — Player 2 (оппонент)
- **Панель управления**: кнопки Start, Pause, Step, Reset
- **Палитра рун**: выбор типа руны для установки
- **Панель лимитов**: показывает, сколько рун каждого типа использовано
- **Панель счёта**: отображает текущий счёт и статистику волны

### Фазы игры

#### Фаза подготовки (Prep) — 8 секунд

- Можно свободно расставлять и удалять руны на поле Player 1
- Мана не движется
- Клик по клетке с выбранной руной — установка/замена руны
- Клик по клетке без выбранной руны — удаление руны

#### Фаза потока (Flow) — 12 секунд

- Мана спавнится и движется по полю
- Редактирование ограничено кулдауном (1 действие раз в 3 секунды)
- Статус редактирования отображается: "Edit: ready" или "Edit in Xs"
- После завершения волны начинается следующая волна с фазой Prep

### Стратегические советы

1. **Планируйте маршруты**: используйте стрелы и отражатели для направления маны в чашу
2. **Используйте разделители**: увеличивайте количество шариков для большего счёта
3. **Ловушки**: отправляйте красную ману оппоненту для максимального эффекта
4. **Чёрная мана**: направляйте её в ловушку, чтобы избежать штрафа
5. **Грязная мана**: старайтесь не доводить её до чаши, направляйте в ловушку или за пределы поля

### Управление

- **Мышь**: клик по клетке для установки/удаления руны
- **Палитра рун**: выбор типа руны перед кликом по полю
- **Start**: запуск/продолжение симуляции
- **Pause**: пауза симуляции
- **Step**: один тик симуляции (для отладки)
- **Reset**: сброс матча и начало заново

### Игровой цикл

- **Тики**: игра симулируется дискретно (10 тиков в секунду)
- **Время жизни шарика**: максимум 40 тиков
- **Спавн маны**: каждые 2 тика
- **Волна**: 20 базовых шариков + грязная мана от оппонента

## Разработка

Проект написан на TypeScript с использованием React и Vite.

### Основные технологии

- **TypeScript**: типизированный JavaScript
- **React 18**: UI библиотека
- **Vite**: сборщик и dev-сервер
- **CSS**: стилизация (без дополнительных фреймворков)

### Архитектура

- **Core (game/)**: чистая логика игры без зависимостей от UI
- **UI (ui/)**: React компоненты для визуализации
- **Разделение ответственности**: движок и UI полностью разделены
